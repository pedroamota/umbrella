# Tranças Store

Demonstração estática publicada em `/trancas-store/` no mesmo deploy do Umbrella.

Origem: https://github.com/pedroamota/trancas-store, `index.html` da branch `main`, consultado em 21/10/2026. Esta é uma cópia local: alterações no repositório de origem não são sincronizadas automaticamente.

CSS extraído para `public/styles.css` para respeitar a CSP do portfólio. Usa fontes locais de fallback, sem solicitar Google Fonts. Conteúdo e links de WhatsApp preservados; abrir a demonstração não envia mensagens automaticamente.

Para atualizar, edite `public/index.html` e `public/styles.css`. O build raiz copia apenas os arquivos desta aplicação para `dist/trancas-store/`.
